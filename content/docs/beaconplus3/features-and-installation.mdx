## Features

BeaconPlus 3 adds upgradeable effects, configurable power, and player access lists to beacons.

- **Effect upgrades** — Create tiers with their own prices, power consumption, and conditions.
- **Power and range** — Choose pyramid block values and calculate range from beacon power.
- **Custom effects** — Use potion effects, flight, crop and spawner boosts, and other bundled effects.
- **Menus and access** — Configure menus, languages, whitelists, blacklists, and team access.
- **Payment options** — Offer money, points, levels, experience, and item currencies.
- **Storage choices** — Store beacon data in world files, plugin files, SQLite, or MySQL.

## Installation

<Steps>
<Step>

### Download BeaconPlus 3

Download the plugin from [SpigotMC](https://www.spigotmc.org/resources/67056/) or [BuiltByBit](https://builtbybit.com/resources/10720/). Use the Java and server versions required by your download. The 3.1.13 build targets Java 21.

</Step>
<Step>

### Install your integrations

Put the BeaconPlus JAR in `plugins/`. Install Vault and an economy provider for money payments, or PlayerPoints for point payments. Experience and item currencies are also available. See [Integrations](./integrations).

</Step>
<Step>

### Restart and configure storage

Restart to generate `plugins/BeaconPlus3/`. Review `storage.yml` before players begin using the plugin. For local player data with world-based beacon storage, configure the following keys inside its existing `Storage` section.

```yaml
Storage:
  Type: FILE
  Beacon Storage Type: WORLD
```

The 3.1.13 player-data selector is `Storage.Type`. Read [Configuration](./configuration) for storage details, then restart to apply your setup.

</Step>
<Step>

### Give and place a beacon

As an administrator, give a beacon to an online player.

```text
/beaconplus give Steve 1
```

Place it on a valid pyramid and right-click it to open its menu. Give players the permissions listed under [Commands & Permissions](./commands-and-permissions).

</Step>
</Steps>
